# adv-dddc
This repository originally contained MATLAB code for **Adversarial Destabilization Attacks to Direct Data-Driven Control**.

A minimal Python reimplementation is provided to run the demonstration scenario of the paper.

## Python Requirements
- Python 3.11+
- numpy
- scipy
- cvxpy

Install dependencies with:
```
pip install numpy scipy cvxpy
```

Run the demonstration with:
```
python main.py
```
